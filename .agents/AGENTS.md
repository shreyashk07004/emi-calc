# Project Agent Rules

## Mirroring Planning Files to Project Folder
For all tasks in this project, copy and mirror all planning artifacts (such as `implementation_plan.md`, `task.md`, and `walkthrough.md`) from the IDE's internal brain directory to a `.planning/` folder in the project root directory. Whenever these files are created or updated, copy them immediately to the `.planning/` folder in the workspace so they are visible in your project tree.
